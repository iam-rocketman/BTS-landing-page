# BTS Landing Page — Share Your Shelfie 🤖📸

A fast, mobile-first landing page created for **Bengaluru Tech Summit 2026** by **ANSCER Robotics**. 

Designed for event booth attendees to effortlessly capture and share their AR250 Autonomous Mobile Robot ("Shelfie") moment on social media with a single tap.

## ✨ Features

- **Dual-Platform Social Sharing:**
  - 🔵 **LinkedIn:** Auto-copies the post caption & opens the LinkedIn app directly via `linkedin://feed` (with automated browser fallback).
  - 🟣 **Instagram:** Auto-copies the post caption & opens the Instagram app directly via `instagram://app` (with automated browser fallback).
- **1-Tap Clipboard Copy:** Automatically loads the pre-formatted caption with event hashtags (`#TakeAShelfie`, `#ANSCERRobotics`, `#BengaluruTechSummit`, `#IndustrialAutomation`, `#AMR`) directly to the clipboard.
- **Responsive & Mobile Optimized:** Fast loading, zero-dependency, self-contained single-page architecture with embedded brand assets.
- **GitHub Pages Ready:** `index.html` configured for instant static hosting.
